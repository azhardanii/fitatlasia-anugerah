# FIT ATLASIA

Production-ready static multi-page website for PT Fit Atlasia Anugerah.

Product is intentionally a single-screen immersive experience: the browser never scrolls on the Product page. Mouse wheel, trackpad gesture, touch swipe, arrow keys and the next-product thumbnail change the active SKU with GSAP transitions.

See README-PRODUCTION.md and DEPLOYMENT-CHECKLIST.md for deployment instructions.
